# Avatar Goal Tracker

A gamified goal-tracking Android app built with Kotlin and Jetpack Compose.

## What it does

- Lets you create tasks (daily habits, goals, etc.)
- Awards XP when you complete tasks
- Tracks progress toward leveling up
- Uses sound effects and animations for feedback
- Persists progress between sessions

## Tech stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Architecture:** Single-activity app with state management
- **Persistence:** SharedPreferences (for now)
- **Tools:** Android Studio, Git, GitHub

## Why I built it

I wanted a goal tracker that feels like an RPG:
- Completing tasks feels like gaining XP
- Progress is visual and satisfying
- Future plans: avatar classes (Warrior, Wizard, Samurai, etc.), streaks, and more
